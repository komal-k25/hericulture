Hericulture - Frontend Prototype

Hericulture is a frontend prototype website showcasing the cultural heritage of Indian states. It currently displays information about the history, dance forms, and languages of selected states.

Features -
State-specific cultural insights: Explore history, languages, and dance forms.
Interactive UI: Clean and simple frontend design for easy navigation.
Currently included states - Tamil Nadu, New Delhi, Uttar Pradesh, Andhra Pradesh.

Tech Stack - HTML5 – Structure of the website, CSS – Styling and layout, JavaScript – Interactive elements.

Future Enhancements - Add more Indian states and their cultural details, include images, videos, and audio of traditional dances and languages,rResponsive design for mobile and tablet users, implement a search and filter option for quick access to information.

Getting Started - 
To run this project locally:
Clone the repository:

git clone https://github.com/komal-k25/hericulture.git
Open index.html in your preferred browser.

Navigate through the states and explore their cultural heritage.
